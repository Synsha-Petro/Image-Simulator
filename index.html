Stage 2: Acquisition & Image Parameters

1. Acquisition Parameters

Estimated SNR
--
SNR ∝ (Voxel Vol × √NSA × B₀) / √RBW
Estimated CNR
--
CNR ∝ |Signal₁ - Signal₂| × SNR (I chose to compare Grey/White Matter for this Simulator)
Estimated SAR
-- W/kg
SAR ∝ (B₀ / 1.5)² × (Flip Angle / 90)² x (2000 / TR) × ETL x (1 / Patient Weight Factor)
Scan Time
--:--
Table Time = ((PEMatrix x TR x NSA) / (ETL x 1000))
In-Plane Resolution
-- mm
Res = FOV / Matrix Size
Out-of-Plane Resolution
-- mm
Thickness = Slice Profile Selection
